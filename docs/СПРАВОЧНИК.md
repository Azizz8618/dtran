# Справочник `dtran` — дизассемблер программ на МАДЛЕН

Для ИИ-агентов.

**`dtran`** — это два инструмента с общим именем:

1. **BESM-6 программа `DTRAN`** — работает на эмуляторе БЭСМ-6 (OS Dispak /
   Монитор-80). Находится на **диске 2048** в постоянной/персональной библиотеке.
   Дизассемблирует объектные модули в псевдоассемблер МАДЛЕН.
   Вызов: `*call dtran(stop*)` (из задания или перфокарты).

2. **Нативный Linux-инструмент** `~/Yandex.Disk/dtran/dtran` — C++ дизассемблер
   объектных модулей БЭСМ-6 (DMS, Pascal-A, Pascal-B), выдающий
   псевдоассемблер МАДЛЕН. Исходник: `~/Yandex.Disk/dtran/dtran.cc`.

Для дисассемблирования программ на БЕМШ используйте **`disbesm6`**
(отдельный инструмент).

---

## 1. BESM-6 программа `DTRAN` (диск 2048)

### 1.1. Запуск

Диск 2048 должен быть подключён в конфигурации эмулятора (dispak.ini):

```ini
attach -e md07 sbor2053.bin    # диск 2053 (системный)
attach -e md05 krab2063.bin    # диск 2063
```

Диск 2048 — это **персональная библиотека** (`perso`), содержащая DTRAN
и другие утилиты.

### 1.2. Пример задания

```
шифр 419999 зс5^
лен 41(2048)^
eeв1а3
*name Dtran
*perso: 411350, cont
*call dtran(stop*)
*assem
*read: 1
*end file
``````
еконец
```

Где:
- `лен 41(2048)^` — лента 41, диск **2048**
- `*perso: 411350, cont` — персональная настройка (шифр 411350)
- `*call dtran(stop*)` — вызов DTRAN с автостопом
- `*assem` — исходный код на МАДЛЕН (или другой транслятор)
- `*read: 1` — чтение данных (перфолента/перфокарта)
- `````` — конец ввода (5-6 обратных кавычек)
- `еконец` — конец задания

### 1.3. Пример задания для дизассемблировки существующего модуля

```
шифр 420000^
лен 41(2048)^
eeв1а3
*name DTRAN
*perso: 411350, cont
*call dtran(stop*)
*assem
*read: 1
*end file
``````
еконец
```

### 1.4. Формат вывода

BESM-6 DTRAN выдаёт псевдоассемблер МАДЛЕН:

```asm
*0000В  :12, VТМ ,*0000В
  -                           , WТС ,GАL/0
*0002В  :  , IТА ,13
  -                           , ХТS ,
*0010В  :  , АТХ ,RЕSТОР*
  -                           , ХТА ,RFМRТFLG
```

### 1.5. Ограничения

- Работает ТОЛЬКО на эмуляторе БЭСМ-6 (dispak или SIMH)
- Требует диск 2048 с программой DTRAN
- Результат — листинг на экране или в печати АЦПУ
- Нет нативного интерфейса на Linux

## 2. Нативный Linux-дизассемблер `dtran`

### 2.1. Сборка

```bash
cd ~/Yandex.Disk/dtran
make            # g++ -O2 -Wall -o dtran dtran.cc
```

Зависимости: только g++. Нет внешних библиотек.

---

## 3. Форматы входных файлов (Linux-дизассемблер)

| Формат | Флаг | Load base | Описание |
|--------|------|-----------|----------|
| **DMS** | `-F dms` | 0 | Объектный модуль Мониторной системы Дубна |
| **Pascal-A** | `-F pa` | 0 | Исполняемый модуль Паскаль-Автокода |
| **Pascal-B** | `-F pb` | 02000₈ | Исполняемый модуль Паскаль-Монитора (постраничный) |

Автоопределение (по умолчанию): DMS -> Pascal-A -> Pascal-B.
При неоднозначности — просьба указать `-F`.

## 5. Опции

### 5.1. Формат входных данных

| Опция | Описание |
|-------|----------|
| `-F dms` | Принудительно DMS-формат |
| `-F pa` | Принудительно Pascal-A |
| `-F pb` | Принудительно Pascal-B |

### 5.2. Формат вывода

| Опция | Описание |
|-------|----------|
| `-l` | Без меток; переассемблируемая форма (ссылки через `/+N`). Паровать с `-e` |
| `-e` | Разворачивать EQU: числовые значения вместо имён (DMS) |
| `-n` | Подавить метки данных `/NNNN` (Pascal) |
| `-o` | Десятичные операнды вместо восьмеричных |
| `-c` | Константные ссылки встраивать литералами |

### 5.3. Восстановление кода/данных

| Опция | Описание |
|-------|----------|
| `-R N` | Базовый регистр N (1..15) для разрешения адресов |
| `-f off` | Граница код/данные (C-радиал: `0x..`, `0..` десятичное) |
| `-E file` | Дополнительные точки входа (по одному смещению на строку) |

### 5.4. Файл команд

| Опция | Описание |
|-------|----------|
| `-D file` | Файл команд (регистронезависимый, по одной команде на строку) |

Команды в файле:
```
code:1000,2050-2077,3001    # диапазоны кода
base:8                      # базовый регистр
iso:100,200-300             # диапазоны текста ISO
gost:400-500                # диапазоны текста ГОСТ
itm:600                     # диапазоны текста ИТМ
text:700-800                # диапазоны текста TEXT
```

### 5.5. Пресеты

| Опция | Описание |
|-------|----------|
| `-d` | Пресет декомпилятора: `-e -o -c -R8` (для `decomp.pl`) |

### 5.6. Справка

| Опция | Описание |
|-------|----------|
| `-h` | Вывод справки и завершение |

## 6. Кодировки

| Кодировка | Флаг `-D` | Описание |
|-----------|-----------|----------|
| ГОСТ 10859 | `gost:` | Основная 6-битная кодировка БЭСМ-6 |
| ISO | `iso:` | 8-битная кодировка (латиница) |
| ITM | `itm:` | Терминальная кодировка |
| TEXT | `text:` | Текстовая кодировка |

Автоопределение: `is_likely_gost`, `is_likely_iso`, `is_likely_text`, `is_likely_itm`
(скоринговая эвристика).

## 7. Структура DMS-модуля

```
+----------------------------+  offset 0
|  Заголовок (packed/unpacked)|
|  - ключ BESM6_MAGIC        |  raw[0] = 0x4245534d3600
|  - comment_off             |
+----------------------------+
|  Секция команд (код)        |  cmd_off .. cmd_off+cmd_len
+----------------------------+
|  Секция констант            |  const_off .. const_off+const_len
+----------------------------+
|  Секция данных (BSS)        |  runtime: cmd_len+const_len .. +bss_len
+----------------------------+
|  Таблица символов           |  gak/5, gak/6, gak/7
+----------------------------+
```

## 8. Формат вывода

### 8.1. Стандартный (с метками)

```asm
 ,XTA ,1
 ,ATX ,2
13,VJM ,SUBR
 ,UJ  ,LOOP
```

### 8.2. Переассемблируемый (-l)

```asm
 ,XTA ,/1
 ,ATX ,/2
13,VJM ,/+3
 ,UJ  ,/-3
```

### 8.3. Константы

```asm
 ,CON ,1234567890ABCDEFH    # числовая константа
 ,ISO ,6HABCDEFGH           # ISO-строка
 ,GOST,8Hабвгдежз           # ГОСТ-строка
 ,TEXT,4Htest               # TEXT-строка
```

### 8.4. BSS-секция

```asm
 ,BSS ,10                   # 10 слов неинициализированной памяти
```

## 9. Команды БЭСМ-6 (таблица opcode)

### 9.1. Арифметика (ACC / X / стек)

| Команда | Описание |
|---------|----------|
| `XTA addr` | Загрузка из памяти в ACC |
| `ATX addr` | Запись ACC в память |
| `XTS addr` | Загрузка из памяти в стек |
| `STX addr` | Запись стека в память |
| `A+X addr` | Сложение ACC + X |
| `A-X addr` | Вычитание ACC - X |
| `X-A addr` | Вычитание X - ACC |
| `AAX addr` | Логическое И |
| `AEX addr` | Исключающее ИЛИ |
| `ARX addr` | Прибавление с переносом |
| `AVX addr` | Последовательное сравнение |
| `AOX addr` | Логическое ИЛИ |
| `A/X addr` | Деление |
| `A*X addr` | Умножение |
| `APX addr` | Сравнение |
| `AUX addr` | Беззнаковое сравнение |
| `ACX addr` | Сравнение с циклическим сдвигом |
| `ANX addr` | Отрицание AND |
| `AMX addr` | Модуль разности |
| `E+X addr` | Сложение с плавающей точкой |
| `E-X addr` | Вычитание с плавающей точкой |
| `ASX addr` | Загрузка с одновременной записью |
| `YTA` | Загрузка из аккумулятора |

### 9.2. Сдвиги

| Команда | Описание |
|---------|----------|
| `ASN 64-N` | Сдвиг ACC влево на N |
| `ASN 64+N` | Сдвиг ACC вправо на N |

### 9.3. Регистровые операции

| Команда | Описание |
|---------|----------|
| `ITA N` | Регистр -> ACC |
| `ATI N` | ACC -> регистр |
| `ITS N` | Регистр -> стек |
| `STI N` | Стек -> регистр |
| `MTJ N,M` | Передача между регистрами |
| `J+M N,M` | Сложение регистров |
| `VTM N, addr` | Загрузка адреса в регистр |
| `UTM N, addr` | Инкремент регистра |
| `VJM N, addr` | Вызов подпрограммы |
| `VZM N, addr` | Выход если ACC=0 |
| `V1M N, addr` | Выход если ACC!=0 |
| `VLM N, addr` | Цикл (декремент + переход) |

### 9.4. Переходы

| Команда | Описание |
|---------|----------|
| `UJ addr` | Безусловный переход |
| `UZA addr` | Переход при ACC=0 |
| `U1A addr` | Переход при ACC!=0 |

### 9.5. Экстракоды

| Команда | Описание |
|---------|----------|
| `*50 arg` | Экстракод 50 |
| `*51 arg` | Экстракод 51 |
| `*60 arg` | Экстракод 60 (ввод/вывод) |
| `*64 arg` | Экстракод 64 |
| `*70 arg` | Экстракод 70 |
| `*74` | Экстракод 74 (стоп) |
| `*76 arg` | Экстракод 76 |

### 9.6. Специальные

| Команда | Описание |
|---------|----------|
| `RTE N` | Чтение регистра |
| `NTR N` | Запись регистра |
| `UTC addr` | Передача тактов |
| `WTC addr` | Запись тактов |
| `CTX` | Передача из тактового генератора |

### 9.7. Директивы

| Команда | Описание |
|---------|----------|
| `NAME` | Имя модуля |
| `EQU` | Эквивалентность |
| `CON` | Константа |
| `BSS` | Блок неинициализированной памяти |
| `END` | Конец модуля |
| `SUBR` | Подпрограмма (точка входа) |

## 10. Примеры использования

### 10.1. Базовая дизассемблировка

```bash
# Автоопределение формата
./dtran object.o

# Принудительно DMS
./dtran -F dms object.o

# Для Pascal-B
./dtran -F pb pascal_exec.bin
```

### 10.2. Для декомпиляции

```bash
# Пресет декомпилятора (подача на decomp.pl)
./dtran -d object.o > disasm.txt
decomp.pl disasm.txt > decompiled.txt
```

### 10.3. Переассемблируемая форма

```bash
./dtran -l -e -o object.o
```

### 10.4. Конвейер: компиляция -> дизассемблирование

```bash
# Компиляция MADLEN-исходника
./asm.sh source.asm
# object.o создан -> дизассемблирование
./dtran -F dms object.o > disasm.txt
```

## 14. Отличия от `disbesm6`

| Параметр | `dtran` | `disbesm6` |
|----------|---------|------------|
| Формат входа | DMS / Pascal-A / Pascal-B | Постоянная библиотека Диспака |
| Язык вывода | МАДЛЕН (псевдоассемблер) | БЕМШ |
| Кодировки | ГОСТ/ISO/ITM/TEXT | ISO |
| Декомпиляция | Да (через -d + decomp.pl) | Нет |
| Таблицы символов | DMS gak / Pascal symtab | Нет |
| Анализ код/данные | Достижимость / -R / -f | Простой скан |
